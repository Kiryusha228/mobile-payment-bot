# Пет-проект: Telegram-бот для пополнения баланса мобильного телефона (Mobile Pay)

Сервис позволяет пополнять баланс мобильного телефона через платёжную систему YooMoney.  
В проекте кошелек YooMoney является агрегатором, принимающим переводы от пользователей, и перенаправляющий их на оплату через витрину магазина.  
Цель проекта - изучение принципов работы платёжных систем.

## В рамках проекта:
- Спроектировал структуру небольшой базы данных и реализовал её взаимодействие с приложением через Hibernate.
- Разработал REST API на Kotlin с использованием Spring Boot.
- Реализовал асинхронное взаимодействие между микросервисами через брокер сообщений Kafka.
- Настроил интеграцию с Telegram API на Java для реализации интерфейса.
- Настроил интеграцию с YooMoney API для реализации пополнения баланса.
- Настроил туннель для localhost с помощью CloudPub для получения вебхуков от YooMoney.
- Развернул проект в Docker-контейнерах.

## Стек технологий:
Kotlin, Java 17, Spring Boot, Hibernate, PostgreSQL, Docker, Docker-compose, Kafka.
